Adds a new `@blizzard-api/wow-forever` package with helpers and response types for the World of Warcraft: Forever (`static-forever` and `dynamic-forever`) game data API. Includes achievements, creature, guild crest, item (and item sets), media search, mount, pet, playable class, playable race, playable specialization, power type, profession, region, reputations, spell, talent, title and toy endpoints. The core package gains the `static-forever` and `dynamic-forever` namespaces for World of Warcraft: Forever in `BlizzardNamespaces`.
